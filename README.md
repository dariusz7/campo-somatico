# Campo Somático · sitio de la propuesta inicial

Sitio estático (HTML + CSS + JS, sin dependencias) publicado con GitHub Pages.

- `index.html`: contenido de la página
- `styles.css`: diseño
- `anim.css` y `anim.js`: animaciones (aparición al hacer scroll, ondas que respiran, contador, barra de progreso). Respetan la opción del sistema "reducir movimiento".
- `script.js`: envío del formulario con [Web3Forms](https://web3forms.com). La clave va en `WEB3FORMS_KEY`, arriba del archivo.
- `Campo-Somatico-Presentacion.pdf`: la presentación descargable

## Versiones

Cada versión publicada lleva una etiqueta de git (`v1.0`, `v2.0`, …). Para ver las versiones: `git tag -n`. Para volver a una: `git checkout v1.0` (y `git checkout main` para regresar).
